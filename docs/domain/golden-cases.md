# 골든 케이스 정의·고정 기대값 (설계서 §7.3)

엔진·모듈 계산 변경 시 `npx vitest run`의 골든 테스트(`tests/golden/golden.test.ts`)를 반드시
실행하고, 아래 고정 기대값(float64 완전 일치)을 통과해야 한다.

## 1. 더미 위험률 표 생성 규칙

- 생성기: `.claude/skills/golden-tests/scripts/gen_table.py`
- 산출물(단일 기준 데이터·공용 라이브러리 시드): `lib/engine/seed/dummy-rates.json`
- 연령 0~100, 소수 6자리 반올림 `round6(q) = floor(q·10⁶ + 0.5) / 10⁶`, 상한 0.999999

표는 **성별을 구분하지 않는다** — 성별은 계약조건(M02)에서만 다루므로 담보 5종으로 제공한다(v2).
일반사망률·암발생률은 v1의 사망률(남)·진단률 산식을 그대로 승계하여 G1~G5 기대값이 변하지 않는다.

| 계열(키) | 산식 | 사망률 플래그 |
|------|------|---------------|
| 일반사망률 (`mortality`) | `round6(0.0005 + 0.00005 · 1.09^x)` | ○ |
| 재해사망률 (`accident`) | `round6(0.00025 + 0.000002 · 1.06^x)` | ○ |
| 50% 이상 장애율 (`disability`) | `round6(0.00008 + 0.000008 · 1.09^x)` | ✕ |
| 암발생률 (`cancer`) | `round6(0.0002 + 0.00002 · 1.08^x)` | ✕ |
| 암수술률 (`cancer_surgery`) | `round6(0.00015 + 0.000015 · 1.08^x)` | ✕ |

참고값: q_일반사망(40) = 0.00207, q_일반사망(59) = 0.008575, q_일반사망(100) = 0.276952
· q_암발생(40) = 0.000634 · q_재해사망(40) = 0.000271 · q_장애50(40) = 0.000331 · q_암수술(40) = 0.000476

구버전(성별 구분) 저장 파일 호환: `male`·`female` → 일반사망률, `diagnosis` → 암발생률로 매핑하며
자산 슬롯(`…:q_male` 등)은 그대로 유지한다(`lib/engine/pipeline.ts`의 `LEGACY_RATE_KEY`).

## 2. 정준 계산 순서

TS 엔진(`lib/engine`)과 독립 Python 이중 산출(`reference.py`)이 **동일한 연산 순서**를 따라
float64 비트 단위 일치를 달성한다. 변경 시 양쪽을 함께 수정해야 한다.

1. `v = 1/(1+i)`, `sqv = sqrt(v)`
2. 할인계수(누적 곱): `vp[0] = 1`, `vp[t+1] = vp[t]·v`
3. 생존자수: `l[0] = l0`, `l[t+1] = l[t]·(1−q[t])` (독립 곱은 원인 순서대로 누적 곱)
4. 사망자수: `d[t] = l[t]·q[t]`
5. 수입현가(연시): `PVin = Σ_{t=0}^{m−1} l[t]·vp[t]` (t 오름차순 순차 누적)
6. 사망 지급현가: 연말 `Σ S·d[t]·vp[t+1]`, 연중 `Σ S·d[t]·(vp[t]·sqv)`, 연시 `Σ S·d[t]·vp[t]`
7. 만기 지급현가: `S·l[n]·vp[n]`
8. `NSP = PVout/l[0]`, `P = PVout/PVin`
9. 방식 A: `G = (PVout + α·S·l0 + β·S·E) / (PVin·(1−γ))`, `E = Σ_{t=0}^{n−1} l[t]·vp[t]`
   - 부가보험료 분해(1건당): `α·S·l0/PVin`, `β·S·E/PVin`, `γ·G`, 합계 `G − P`
10. G5 특약(복수 탈퇴원인 독립 곱): `l[t+1] = l[t]·(1−q_일반사망[t])·(1−q_암발생[t])`
    — 원인 순서는 선택 순서(일반사망 → 암발생)로 고정, `d_암발생[t] = l[t]·q_암발생[t]`

곱셈·덧셈은 표기된 좌→우 순서, 합산은 t 오름차순 순차 누적. `^0.5`는 pow가 아닌 `sqrt` 사용.

## 4. 기대값 재생성 절차

기대값은 케이스 정의 자체가 바뀔 때만 재생성한다(엔진 수정으로 값을 맞추는 방향 금지).

```bash
python .claude/skills/golden-tests/scripts/gen_table.py    # 표 규칙 변경 시에만
python .claude/skills/golden-tests/scripts/reference.py    # expected.json 재생성
npx vitest run                                             # 완전 일치 확인
```

`reference.py`는 앱 엔진·코드 생성 템플릿과 코드를 일절 공유하지 않는 독립 경로로 유지한다.

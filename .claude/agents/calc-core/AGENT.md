# calc-core — 계산 엔진 서브에이전트 (설계서 §6.3)

## 역할

계산 엔진(계열 연산·탈퇴·현가·보험료), 수식 파서·평가기, 골든 테스트를 담당한다.
트리거: 계산 로직 신설·수정.

- 입력: 설계서 §3, `docs/domain/golden-cases.md`
- 출력: `lib/engine/`, `lib/formula/`, 테스트 리포트

## 불변 규칙

1. **정확도 최우선**: 내부 계산은 float64 중간 미반올림. 표시 자릿수는 UI 관심사.
2. **결정론**: 동일 입력 → 동일 출력. 계산 경로에 LLM·`eval`·`new Function` 금지.
3. **정준 계산 순서**(`docs/domain/golden-cases.md` §2)를 벗어나는 연산 순서 변경 금지 —
   독립 Python 이중 산출과 float64 완전 일치가 통과 조건이다.
4. 엔진·수식 평가 수정 시 `npx vitest run` 골든 테스트(G1~G4, P3부터 G5) 필수 실행.
5. 기대값을 엔진에 맞추는 방향의 수정 금지. 케이스 정의가 바뀔 때만
   `reference.py`로 재생성하고 문서를 갱신한다.
6. 다른 서브에이전트 직접 호출 금지 — 메인이 조율한다. 큰 산출물은 `/output/step{n}_*.json`.
